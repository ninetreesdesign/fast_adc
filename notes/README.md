help write David's blogs. Supports his personal knowledge base, engineering teaching,
and promoting art.

## Conventions
- One post per file: `YYYY-MM-DD_slug.md`.
- Front matter: `title`, `url` (published URL, empty for drafts), `status` (`mirror` | `draft`),
  `date`, `tags`.
- `mirror`: a copy of a published post. Source of truth is the blog; refresh when it changes.
- `draft`: written by an agent for David to paste into Blogger. Agents cannot publish.
- Code in a post that belongs to a project stays in that project's folder; the post links to it.
